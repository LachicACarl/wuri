# CHED HEI data-request brief

## Status and use

This is an editable preparation document for a researcher-initiated request
to the Commission on Higher Education (CHED). It has not been sent, filed,
or submitted through any form. It does not establish that CHED will provide
the requested data, that the requested fields exist, or that any source has
been acquired.

The request is intended to obtain a permitted, dated source artifact for the
candidate Philippine higher education institution (HEI) population frame.
It is not a request for institutional evidence, participation, ranking data,
or access to private institutional records.

The current research design remains a mixed platform/research design with
stratified purposive sampling as a leading proposal, not an approved method.
The population frame is not frozen, the institutional sample size is
unresolved, and the A0 protocol remains
`pending_researcher_approval`.

The 2025 first-edition Citizen's Charter publishes a service titled
**Request for CHED Statistical Data/Information**. It identifies the Office
of Planning, Research and Knowledge Management, Knowledge Management
Division, Information Management Unit; states that an individual/client may
avail; describes a formal request letter stating purpose and usage with
contact details including email; describes an online request route and
release by email or fax; and lists no fee. These details describe that
published 2025 edition, not a guarantee that the current process is
unchanged.

The official Contact Us page publishes `info@ched.gov.ph`, the Public
Assistance and Complaints Desk at `(02) 8441-1260`, and the CHED Hotline at
`0999-4445-996`. The researcher must confirm the appropriate current channel
and submission instructions before sending this brief.

The HEIDA landing page was reachable but did not yield a dated export. The
legacy list page did not yield a usable list snapshot. Direct retrieval of
some official pages and the Citizen's Charter PDF remained blocked in this
environment; the published procedure and contact details above are recorded
from the official indexed sources supplied for this correction. No source
artifact has been acquired.

## Academic purpose

The requester is preparing a university-ranking readiness research platform
and dissertation study. The requested information would be used only to
construct and document a candidate population frame of Philippine HEIs. The
frame will support transparent population definition and later adviser
review; it will not itself establish institutional participation, framework
eligibility, evidence authorization, or a ranking result.

The requester will preserve the original CHED artifact unchanged, record its
source URL or approved delivery path, retrieval timestamp, publication or
reporting period, file metadata, SHA-256 hash, scope, and access conditions.
Any derived frame will preserve raw source values and document
standardization, duplicate handling, unresolved records, and researcher
decisions.

The request does not seek personal information. If any supplied file contains
personal or restricted information, the requester asks CHED to identify the
restriction and provide an appropriate redacted or aggregate alternative.

## Requested reference period

Please provide the most recent official institution-level HEI listing or
machine-readable directory source that CHED considers suitable for
identifying Philippine HEIs, together with its publication/update date and
reference period. If the latest complete source differs from the requested
period, please identify the available period and explain the difference.

CHED's published statistics report an aggregate of **2,334 HEIs as of June
26, 2025**. The table includes BARMM SUC main and satellite campuses but
explicitly excludes **85 BARMM private HEIs and 7 other government HEIs**.
This is useful historical coverage evidence, not a substitute for the
requested institution-level artifact.

The research notes currently refer to a reported June 2025 figure, but that
figure is not being treated as a verified population count. The request asks
CHED to identify the authoritative date and scope rather than presuming that
figure is current or complete.

## Requested source and fields

If maintained and releasable, please provide an official CSV, XLSX, XLS,
JSON, or other machine-readable listing. If no machine-readable file is
available, a stable official publication or directory export is acceptable.

The requester asks whether the source includes the following fields:

- Stable CHED or other institution identifier.
- Official institution name.
- Former, alternate, or historical names, if maintained.
- Public/private or other sector classification.
- Institution type.
- Region and other geographic classification.
- Province, city/municipality, or location fields, if maintained.
- Operational or recognition status.
- Institution, campus, branch, and parent-child relationships.
- Main/satellite/campus designation, if maintained.
- Publication/update date and reference period.
- Source unit definition: institution, campus, branch, program, or another
  record type.

The requested list is not a claim that all fields exist in CHED systems.
Please identify unavailable fields rather than filling them with inferred
values.

## Requested documentation and conditions

Please also identify, for the supplied artifact or publication:

- The definition of an HEI record.
- Coverage scope and geographic coverage.
- Included and excluded institution types or sectors.
- Any BARMM or other geographic limitations.
- Treatment of campuses, branches, mergers, renamings, and closures.
- Duplicate detection or deduplication rules.
- Known missing, stale, or conflicting records.
- Publication/update schedule and source version.
- Citation requirements.
- Redistribution, licensing, data-use, or research-use conditions.
- Privacy, confidentiality, retention, and deletion requirements.
- Whether the supplied artifact may be retained as an immutable research
  source snapshot and cited in a dissertation.

## Proposed source handling

If CHED provides an artifact, the researcher will:

1. Preserve the original file or response without modification.
2. Record the delivery route, source URL/path, issuer, retrieval time,
   publication/update date, reference period, file type, byte size, and
   SHA-256 hash.
3. Store the private source outside the committed application and
   documentation tree where required.
4. Produce a separate read-only inspection report with raw row/column counts,
   fields, missing values, and duplicate identifiers.
5. Keep institution, campus, branch, and program units distinct.
6. Record every later inclusion, exclusion, merge, split, and unresolved
   decision in an auditable change log.
7. Follow CHED's stated citation, access, retention, and redistribution
   conditions.

The source would remain a candidate frame input until the researcher and
adviser approve the reconciliation procedure, unit definitions, coverage
limitations, and frame version.

## Fallback plan

If CHED cannot provide the requested artifact:

- request the appropriate official publication, statistical table, or
  directory-export route instead of reconstructing records from search
  results;
- request confirmation of the authoritative source name, reference period,
  and citation;
- document the refusal, access limitation, or unavailable fields without
  treating absence as evidence that an institution is not an HEI;
- retain the candidate frame as unresolved and report that no verified
  national count is available;
- seek adviser approval for a revised, explicitly limited population scope
  only if an official source cannot be obtained.

The fallback must not use unauthorized scraping, inferred identifiers,
fabricated records, or an unverified aggregate count as an institution list.
