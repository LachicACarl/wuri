# Chapter 3 methodology traceability

## Source reviewed

The authoritative source reviewed for this matrix is `UniversityRanking_V3.1.docx`, copied unchanged into the ignored `backend/private/research-input/` folder from the local Downloads folder. The source file was readable as a Word document. It contains no `comments.xml` and no tracked insertions/deletions; separate adviser comments were not supplied and cannot be inferred.

The status vocabulary is:

- `verified_aligned`: Chapter 3 states the requirement and the relevant implementation behavior matches it.
- `implementation_gap`: Chapter 3 states a requirement, but the relevant implementation is missing, incomplete, or materially different.
- `requires_researcher_decision`: Chapter 3 leaves a material operational choice open.
- `source_unavailable`: the needed source, data, or authoritative catalog could not be verified in the available materials.

## Protocol alignment and execution state

The protocol draft now records that Chapter 3 was directly reviewed and captures the verified study scope and explicit methodological requirements. It remains `pending_researcher_approval`; the exact baseline model, official catalogs/weights, retrieval conventions, operational EQAM rubrics/calibration, criterion aggregation, five-expert agreement/consensus process, and adviser approval are not resolved. The implementation’s query and metric conventions remain unapproved candidates.

The A0 runner currently supports an A0 retrieval-component evaluation only. It does not implement Chapter 3 Table 3.9's complete A0 pretrained Sentence-BERT plus conventional AHP-TOPSIS readiness baseline. No A0–A4 run or readiness scoring was performed in this alignment phase.
